# Sentiment Analysis Web App using Python

## About the Project

This project analyzes text reviews and identifies their sentiment as Positive, Neutral, or Negative using a pretrained Transformer model from Hugging Face.

The application is built with Python and Streamlit and provides an interactive interface for analyzing individual reviews and multiple reviews from a CSV file.

## Features

* Analyze individual text reviews.
* Analyze multiple reviews through CSV upload.
* Classify sentiment as Positive, Neutral, or Negative.
* Display confidence scores.
* Show sentiment counts, percentages, and a bar chart.
* Display detailed analysis results.
* Download results as a CSV file.

## Technologies Used

* Python
* Streamlit
* Hugging Face Transformers
* CardiffNLP RoBERTa sentiment model
* Pandas

## How to Run the Project

1. Install Python.

2. Install the required libraries:

   `python -m pip install streamlit transformers torch pandas`

3. Open the project folder in PowerShell.

4. Run the application:

   `python -m streamlit run app_ui.py`

5. Open the local URL displayed in the terminal.

## Project Files

* `app_ui.py` — Streamlit web interface and sentiment analysis.
* `app.py` — Terminal-based analysis of reviews stored in a CSV file.
* `reviews.csv` — Sample input reviews.
* `results.csv` — Output generated by the terminal-based program.

## Model

The application uses `cardiffnlp/twitter-roberta-base-sentiment-latest`, a pretrained model that predicts positive, neutral, and negative sentiment.

## Limitations

Predictions may be inaccurate for sarcasm, mixed opinions, context-dependent statements, or text unlike the data the model was trained on. Confidence scores are not guarantees of correctness.
